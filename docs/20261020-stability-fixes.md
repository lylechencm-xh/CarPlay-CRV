# 2026-10-20 CR-V 连接与音视频稳定性修复

依据 `_carlogs/20261020/日志分析.md`，并纳入“连接成功后退回连接页、重复自动连接”的用户反馈。

## 已实现的修改

- **连接页与视频分离**：使用明确的会话事件和当前 decoder 的渲染回调驱动显示。协议 ACTIVE 不再等同于已经出画；普通诊断文本不再把画面切回连接页。旧控制器的事件受连接 epoch 隔离。
- **首帧与显示恢复**：Surface 或主视频流替换后重新等待首帧。可见且有 Surface 时，每 10 秒检查一次，最多两次请求局部视频恢复；仍无输出时保留音频、USB 和会话，提示用户手动重试。后台及无 Surface 的时间不消耗局部恢复次数。
- **自动重连上限**：所有真正的控制器启动共用最多五次预算（首次加四次重试）。USB attach、重枚举、Surface 回调及 Activity 重建不清零预算。用户手动连接/切换模式，或至少一分钟且近期仍有渲染的会话才能重置；静态画面不触发无谓恢复，但也保守地不依赖空闲时间清零预算。
- **重复 USB 打开**：已有控制器、待启动 USB 会话或打开操作时忽略重复入口；因 Surface 不在而推迟的重试在 Surface 恢复后仍遵守同一调度和预算。
- **会话结束归属**：从未成为活动 CarPlay 会话的探测/配对 TCP 连接关闭不再触发完整重连；等待真正连接成功仍有原有握手超时约束。活动会话归属切换与终止判定使用短临界区，避免旧会话结束误关替代会话。
- **VPN 授权门控**：控制器启动入口及工作线程启动前再次检查授权；拒绝/取消授权后停止自动连接。`establish returned null` 进入等待授权/人工检查路径，不再盲目重跑 NCM、Lockdown 和 MFi。增加授权结果诊断。这不意味着已证明每次 null 都由拒绝授权造成。
- **视频配置去重**：新 decoder 的缓存配置只提交一次；队列合并相同待处理配置，工作线程按 codec 和完整配置字节判断，健康 decoder 收到相同配置不再 release/create、清空参考链或请求关键帧。decoder 已失效时允许相同配置重新建立；真实内容变化及 Surface 恢复仍可重建。
- **视频负载**：保留 1280×720 和触控坐标，将 CR-V 的协商最高帧率降至 20 FPS。增加独立的接收能力上限，普通设备的 FPS 设置保持原规则。去除解码诊断双路打印，增加实际配置原因、generation、重复配置计数、解密字节量和单位数据 CPU 成本。完整认证校验与 nonce 顺序保留。是否足以降低实车解密占用需再次采样，未引入未经验证的原生密码实现。
- **音频接收隔离**：UDP 线程只接收、记录序号并投递拥有独立字节数组的数据包；单个工作线程按顺序验证认证和回调。接收队列最多 64 包、最长 80ms，过载丢弃与过期分别计数。关闭会唤醒等待线程，不把旧数据送入新流。
- **播放积压**：待播 LPCM 按实际字节量控制，音乐最多约 200ms、语音约 100ms，并在取出时淘汰过期包。音乐预缓冲从 300ms 改为 120ms，首选 AudioTrack 目标约 220ms，仍服从设备最小缓冲及初始化回退。对手机声明的预缓冲同步为 120ms。实际内核/AudioTrack 上限可能高于目标。
- **热点备份**：修复快照对象身份比较导致的恒定误报，按 SSID、隐藏标志、认证、加密集合和可核验密码进行内容比较。失败只输出字段名称，不输出 SSID 或密码；不能验证的备份仍拒绝更改原配置。

## 实车验收（不能用单元测试代替）

1. 连续冷启动、插拔各十次；首次授权批准/取消/拒绝后再批准。拒绝时不得循环重连，批准后仅启动一个控制器。
2. 固定画面、动态地图、音乐加导航各运行；确认连接成功后稳定进入画面。记录页面切换原因、配置摘要、generation、最长无输出时间。
3. 制造首帧迟到与 decoder 恢复；核对仅恢复视频，自动连接最多五次，达到上限后 USB/Surface 事件不绕过停止状态。点击连接可开启新一轮。
4. 前后台及原厂页面切换二十次；Surface 销毁时保持音频与传输，新 Surface 到来后恢复画面。
5. 动态地图加音乐持续至少一小时；分别统计 UDP 序号缺口、接收队列溢出/过期、播放队列丢弃和再缓冲。比较相同数据量下解密成本，不能仅凭低帧龄宣布改善。
6. 验证点按、滑动、导航增益和语音；热点启动、异常停止、拔线接管及插线恢复后核对原厂配置。日志无法证明这些项目已经实车通过。

普通 source-only debug 构建不等于带已配置 MFi 身份及车机签名的实车安装包；未经对应打包流程，不应用它替换现用实车包。
